pharma-recall
An interactive, web-based pharmacology study platform designed to help students and healthcare learners master medication knowledge through active recall, flashcards, structured drug data, and targeted practice modes.

Live Demo

Features
Interactive Flashcards: Test your knowledge of core pharmaceutical categories, mechanisms of action, and clinical pearls.

Active Recall Practice: Dynamic practice modes designed to reinforce long-term memory retention and board exam preparation.

Structured Drug Resources: Curated data tables and modular scripts (data/drugs.js) breaking down drug classifications, side effects, and indications.

Responsive Design: Clean, lightweight user interface built with vanilla web technologies for seamless studying across desktop and mobile devices.

Tech Stack
Frontend: HTML5, CSS3, JavaScript (Vanilla ES6+)

Hosting: GitHub Pages

Getting Started
To run or modify this project locally, follow these simple steps:

Clone the repository:

Bash
git clone https://github.com/flowingcity777/pharma-recall.git
Navigate to the project directory:

Bash
cd pharma-recall
Open the project:
Open index.html directly in your preferred web browser, or launch it using a local development server (such as Live Server in VS Code).
